# Hán Ngữ Mỗi Ngày

Web học tiếng Trung miễn phí cho người Việt, từ pinyin đến HSK 6.

**Dùng thử:** https://cyber-trunghl.github.io/Chinese-Every-Day/

## Tính năng

- **Pinyin và thanh điệu:** thanh mẫu, vận mẫu, 4 thanh điệu, luyện nghe.
- **Chữ Hán:** nét cơ bản, bộ thủ, luyện viết từng nét.
- **Từ vựng HSK 1–6:** 4991 từ, có pinyin, nghĩa tiếng Việt và âm Hán Việt.
- **Ngữ pháp** trọng tâm kèm ví dụ.
- **Flashcard** ôn từ theo chu kỳ nhắc lại.
- **Kiểm tra** trắc nghiệm 10 câu.
- **Dịch** Việt – Trung và phân tích câu.
- Giao diện sáng, tối hoặc theo hệ thống. Tiến độ học lưu ngay trên trình duyệt.

## Chạy trên máy

Cần cài [Node.js](https://nodejs.org) (bản 20 trở lên).
Mở http://localhost:5173 để xem web.
